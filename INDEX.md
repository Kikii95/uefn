## 📝 Template Sub-Projet

Pour ajouter un nouveau sub-projet, créer :

```
<nom-du-jeu>/
├── README.md           # Description, concept, inspirations
├── BACKLOG.md          # Tâches à faire
├── game-design.md      # GDD complet (rules, scoring, flow)
└── verse/              # Code Verse
    └── <fichiers>.verse
```

Puis mettre à jour :
1. Ce fichier (INDEX.md) → ajouter la ligne au tableau
2. `sync.sh` → ajouter le mapping dans PROJECT_MAP
